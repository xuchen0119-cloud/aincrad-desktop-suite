# 将结衣导入自己的 ChatGPT Work

这里的 `spritesheet.png` 是透明 v2 桌宠图集：1536 × 2288，单格 192 × 208，73 个有效帧，包括九组状态和十六个视线方向。

1. 在支持自定义桌宠的 ChatGPT Work 中启用 / 使用桌宠功能。
2. 附上本文件夹的 `spritesheet.png`，发送下面的请求：

   > 请验证附件中的 v2 桌宠图集，用它创建“结衣 Yui”桌宠并启用。图集是成品，无需重新生成。描述：黑长发白裙的结衣，陪伴我聊天、思考与工作的小小精灵。

3. 等待图集验证、创建和启用确认。遇到尺寸或版本问题时，请勿裁切整张图集，优先查看 `layout.json` 和账号当前支持的桌宠功能。

预览位于 `preview/`，包含每组动作 GIF、整套动作 MP4、转头循环及待机到跳跃的衔接。`source/` 保留生成的图像原稿，粉色为制作时使用的可移除背景，不是桌宠显示背景。

本包不会自动登录或操作你的账号，也没有包含发布者的桌宠账号 ID / 上传记录。桌宠仅在支持的 ChatGPT Work 环境中使用，不是独立的全系统 Windows 桌宠程序。
